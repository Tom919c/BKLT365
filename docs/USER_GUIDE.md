# 逆光365 主编用户手册

版本：v2
适用入口：`http://127.0.0.1:8501`（局域网）或 `https://365.niguang.me`（公网）
适用对象：轮值主编

> 这本书只讲“怎么用”，不要求看代码。系统同一时间只允许一个主编登录；第二台设备登录会让第一台失效。

## 1. 登录

1. 打开网页，输入工作室共享密码。
2. 进入“工作台”。
3. 如果提示“登录已失效”，说明另一台设备已登录；确认后重新登录即可。

页面顶部显示当前周；可在“查看周”切换历史周。

## 2. 同步飞书

1. 在工作台点击“同步飞书”。
2. 系统只读拉取**当前周**的投稿记录，不会写回飞书、不会自动发布。
3. 一条飞书记录显示为一个“投稿组”卡片；组内全部图片一起处理。
4. 同一位摄影师同一天提交多次，仍是多个组。
5. 重复点击同步是幂等的：已有组和文件不会重复增加。

同步结果可能出现：

- 新组：进入“待入选”。
- 记录被编辑：组信息/图说更新。
- 飞书附件被删除：本地图片保留，卡片标记“飞书附件已移除，本地保留”。
- 文件名冲突/非图片：卡片显示明确提示，不会静默覆盖。

## 3. 选中一个组（按组入选）

1. 在组卡片点“按组入选”。
2. 选择“入选日期”（默认今天，可改；这是实际发布/入选日期，不是投稿日）。
3. 整组图片立即改名：`投稿日_摄影师_图名[序号]（MMDD入选）.扩展名`。
4. 单图不添加序号；多图从 1 开始；不会出现 `_1` 或前导零。
5. 取消入选：点“取消入选”，整组移除 `（MMDD入选）` 后缀。

注意：

- 不能只选组内一张图。需要拆组时，先在飞书侧处理记录，再重新同步。
- 如果文件名中的投稿日与入选日不同，系统只提示“日期矛盾”，不拦截；由主编决定。
- 已发布组不能取消入选；需要处理时先确认平台侧状态。

## 4. 编辑图名/图说、调顺序

- “改图名/图说”：修改组级作品名和图说。图说允许 emoji、换行；系统不做内容审核。
- “调顺序”：调整组内图片顺序，发布时按该顺序上传。
- 图说是可选项；摄影师没填就留空，正文不生成图说段。
- 账号按姓名精确匹配“摄影师账号 CSV”；没有映射时只写姓名，不阻断发布。

## 5. 合并多组为一篇笔记

适用：两位摄影师投稿同一主题，希望在同一篇小红书笔记发布。

1. 在工作台勾选多个“已入选”组（底部出现“已选 N 组”）。
2. 点“组稿”。
3. 填写标题（合并笔记的标题由主编填写）。
4. 系统按页范围生成正文：`p1-p3:《作品名1》`、摄影师、图说；下一组继续连续页码。
5. 图片按组顺序、组内顺序汇总；总数守恒。
6. 本地目录不合并，文件仍留在各自原周目录；合并关系记录在笔记的 `note_groups`。

## 6. 编辑笔记与实时话题

在“笔记”页打开笔记：

- 标题、dayNNNN、发布日期、账号、正文均可编辑（已发布后只读）。
- 正文最后一行必须是标签；固定标签自动保留。
- “刷新实时话题”：系统实时读取小红书话题浏览量和获取时间。
- 可手动增删动态话题；固定标签不要手动写进动态话题输入框。
- 实时话题失败会明确提示；不会静默使用旧缓存。可以人工选择后继续。

默认话题：2 个固定 + 3—4 个动态，总数 5—6，上限 10。话题按“浏览量高 + 内容贴合”选择，不使用点赞/播放数据。

## 7. 生成草稿

1. 在笔记预览中点“生成草稿”。
2. 服务端通过项目 Chrome 的小红书创作者后台创建**独立草稿**，并填入标题、正文、图片和话题。
3. 系统保存草稿定位与内容指纹；不会覆盖或删除其他草稿。
4. 草稿生成后，点“打开后台”跳转到已登录的创作者页面。
5. 在后台人工预览：标题、正文、图片顺序、图说、emoji、标签。

如果草稿失败：

- 页面显示失败原因；不会伪造成功。
- 检查项目 Chrome/CDP 是否在线、创作者账号是否登录。
- 修复后重新生成；每次生成都是新草稿，不会复用旧草稿。

## 8. 发布

1. 确认后台预览无误。
2. 回到 Web 笔记页，点“发布”。
3. 勾选“我已在后台预览，确认标题、正文、图片和话题无误”。
4. 点“确认发布”。
5. 服务端会重新匹配当前草稿，复核标题/正文/图片数/话题，然后点击小红书原生发布按钮。
6. 成功后保存笔记 URL、发布时间、账号；组状态变为已发布。

发布结果不确定时：

- 页面提示“结果不确定，请人工核对”，不会自动重试。
- 去小红书后台确认是否已发布；不要连续点击发布。
- 组保持已入选；确认未发布后可重新生成/发布，确认已发布则人工处理状态。

## 9. 周收束

1. 在“归档”页点“收束当前周”。
2. 系统先检查“已入选未发布”的组：
   - 有 → 明确阻断，提示先发布或取消入选；
   - 无 → 未入选组统一改名为 `（未入选）`。
3. 已发布组跳过；已上传周中新增的组也会被处理。
4. 收束是幂等的：目标文件名未变化的组不会重复写库。

## 10. 上传 123 云盘

1. 确认“设置 → 123 年度根目录”正确（当前默认 `2026-2027`，2027 年可改 `2027-2028`）。
2. 在“归档”页点“上传本周文件夹”。
3. 系统先收束并检查阻断，再上传整个周目录。
4. 上传后回读文件数、名称、大小、结构；成功后周状态 `uploaded`。
5. 失败会写入任务记录，刷新不会消失；修复后点“重试”。

跨周入选：

- 未入选组在后续周再次入选时，文件仍留在原周目录，并标记“需重新上传”。
- 上传时先把新入选文件传到 123 并核验，再只清理明确对应的旧“未入选”文件。
- 清理失败显示“已上传·待清理旧文件”，不会把任务标成完全成功。

## 11. 设置

- 123 年度根目录
- 上传星期/小时/分钟（默认周一 20:00）
- 固定标签、动态话题数量、话题总数上限
- 测试/正式发布模式
- 正式账号发布授权
- 开机自启总开关（只记录，不在网页修改本机系统）
- 共享密码修改
- 查看数据根、周目录父路径、状态目录、账号 CSV、数据库路径
- 检查连接（数据库/小红书 CDP）
- 摄影师账号 CSV 导入/查看映射
- 工作室部署清单（电源、Web 自启、Chrome/CDP、Tunnel、防火墙、共享密码）
- 最近审计

正式发布前必须确认：

1. 发布模式为“正式账号发布”。
2. “本轮已取得正式账号发布授权”已勾选。
3. 当前 Chrome 登录的是工作室正式账号。
4. 后台预览无误。

## 12. 常见问题

**Q：同步后没有当天投稿？**
A：看本周其他组；系统展示本周未发布组。当天无投稿时不会伪造记录。

**Q：为什么文件名带 `（1113入选）`，但投稿日是 1115？**
A：入选日期可以早于/晚于投稿日，系统只提示日期矛盾；文件名用实际入选日。

**Q：跨周还能入选吗？**
A：可以。仍留在原周目录，标记需同步；上传时处理新旧文件。

**Q：刷新后上传失败不见了？**
A：不会。失败在数据库/归档任务列表持久显示；除非人工处理或成功重试。

**Q：第二台手机登录后第一台失效？**
A：这是单会话设计；新登录自动接管。旧设备下一次请求会提示重新登录。

**Q：可以只用 CLI 发布吗？**
A：不再支持作为主流程。Web 是唯一发布入口；CLI 仅维护/诊断。
